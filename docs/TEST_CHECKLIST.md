# 관리자 기능 테스트 체크리스트

전체 관리자 기능이 정상적으로 작동하는지 확인하기 위한 체크리스트입니다.

## 사전 준비

- [ ] 개발 서버 실행: `npm run dev`
- [ ] Supabase 로컬 인스턴스 실행 중: `npm run supabase:status`
- [ ] 브라우저에서 `http://localhost:3000` 접속 확인

---

## 1. 권한 및 인증 테스트

### 1.1 관리자 로그인
- [ ] `/login` 페이지 접속
- [ ] `admin001@test.ai` / `qwer1234(예시)`로 로그인
- [ ] 로그인 성공 후 홈페이지로 이동 확인
- [ ] 헤더에 사용자 메뉴 표시 확인

### 1.2 관리자 페이지 접근
- [ ] `/admin` URL 직접 입력
- [ ] 관리자 대시보드 접속 확인
- [ ] 헤더에 "⭐ 관리자 대시보드" 표시 확인
- [ ] 통계 카드 4개 표시 확인 (도시, 작업공간, 리뷰, 사용자)

### 1.3 일반 사용자 접근 차단
- [ ] 로그아웃
- [ ] 일반 사용자 계정 생성 (또는 로그인)
- [ ] `/admin` 접속 시도
- [ ] 홈페이지(`/`)로 리디렉션 확인
- [ ] URL에 `?error=unauthorized` 파라미터 확인

### 1.4 미인증 사용자 접근 차단
- [ ] 로그아웃
- [ ] `/admin` 접속 시도
- [ ] `/login?redirect=/admin`으로 리디렉션 확인

## 2. 도시 관리 테스트

### 2.1 도시 목록 조회
- [ ] 관리자 로그인 상태
- [ ] `/admin/cities` 접속
- [ ] 기존 도시 목록 표시 확인 (15개)
- [ ] 각 도시의 정보 표시 확인 (순위, 이름, 지역, 평점, 리뷰, 생활비)
- [ ] 이미지 썸네일 표시 확인

### 2.2 도시 생성
- [ ] "새 도시 추가" 버튼 클릭
- [ ] `/admin/cities/new` 페이지 이동 확인
- [ ] 폼에 필수 항목 입력:
  - 도시명 (한글): "테스트시"
  - 지역: "서울"
  - 행정구역: "서울특별시"
- [ ] 선택 항목 입력 (평점, 생활비 등)
- [ ] "생성하기" 버튼 클릭
- [ ] 도시 목록 페이지로 리디렉션 확인
- [ ] 새로 생성한 도시 표시 확인
- [ ] 홈페이지에서도 새 도시 표시 확인

### 2.3 도시 수정
- [ ] 도시 목록에서 "테스트시" 옆 "수정" 링크 클릭
- [ ] 수정 페이지로 이동 확인
- [ ] 기존 데이터 폼에 채워져 있는지 확인
- [ ] 평점을 5.0으로 변경
- [ ] "수정하기" 버튼 클릭
- [ ] 목록으로 돌아가서 변경사항 확인

### 2.4 도시 삭제
- [ ] "테스트시" 옆 "삭제" 링크 클릭
- [ ] 확인 다이얼로그 표시 확인
- [ ] 다이얼로그에 CASCADE 경고 메시지 확인
- [ ] "확인" 클릭
- [ ] 목록에서 도시 제거 확인
- [ ] 홈페이지에서도 도시 제거 확인

- [ ] 도시 생성 시 도시명 입력 안 하고 "생성하기" 클릭

- [ ] 일반 사용자로 로그인

  ```javascript
  // 콘솔에서 실행 (예시)
  fetch('/api/admin/delete-city', {
    method: 'POST',
    body: JSON.stringify({ cityId: 'some-id' })
  })
  ```
- [ ] 권한 에러 또는 리디렉션 확인

### 6.3 네트워크 에러 처리
- [ ] Supabase 로컬 인스턴스 중지: `npm run supabase:stop`
- [ ] 관리자 대시보드 접속
- [ ] 적절한 에러 메시지 표시 확인
- [ ] Supabase 재시작: `npm run supabase:start`

## 8. 데이터베이스 일관성 테스트

### 8.1 RLS 정책 확인
- [ ] Supabase Studio 접속: `http://localhost:54323`
- [ ] SQL Editor에서 다음 쿼리 실행:
  ```sql
  -- 일반 사용자 세션에서 (세션 설정 필요)
  SELECT * FROM user_reviews WHERE hidden = true;
  -- 결과: 0개 (RLS로 필터링)
  ```
- [ ] 관리자 세션에서 실행:
